# Kareem Abu Ayyash — Portfolio

A responsive Arabic/English portfolio site built with plain HTML, CSS, and JavaScript. No build step required.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `KareemAbuayyash.github.io` (or any repo name).
2. Upload the files in this folder to the repository root.
3. In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/ (root)`.
4. Your site will appear at `https://KareemAbuayyash.github.io/` (for the special repository name) or the project URL GitHub shows.

## Publish with Netlify
Drag this folder into Netlify Drop, or connect its GitHub repository. No build command is needed; publish directory is `.`.

## Update your details
Edit `index.html` to change text, contact details, links, projects, and achievements. Main colors and layout are in `style.css`.

## Before publishing
- Verify all project descriptions and dates.
- Add real screenshots or links to Sight and Fluento if available.
- The CV path itself is not exposed in the site; only selected resume details are included.
